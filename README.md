# 🛒 NovaCart E-Commerce Business Analytics Project

## 📌 Project Overview

NovaCart Analytics Project is an end-to-end E-Commerce Business Intelligence project built to analyze sales performance, customer behavior, product performance, supplier efficiency, inventory, and returns. This project demonstrates a complete Data Analytics workflow using SQL, Python, Power BI, and GitHub.

---

## 🎯 Business Objective

The objective of this project is to transform raw business data into meaningful insights that help management make data-driven decisions.
